# 🚀 Roadmap: Retrofit P2P Messenger (ICQ-inspired)

Этот план ориентирован на максимальное сокращение времени до получения первого рабочего прототипа (MVP), который можно пощупать на реальных устройствах. Каждый этап представляет собой сквозную (e2e) фичу, укладывающуюся в один Scrum-спринт (около 2 недель).

---

## 📅 Спринт 1: «Hello, P2P World!» (Связующий каркас)
**Цель спринта:** Связать два устройства напрямую и передать текстовый пакет без участия центральных серверов.

### 💻 Бэкенд / Сетевое ядро (Фича: P2P Connection)
*   **Задача:** Написание консольной CLI-утилиты на Go с использованием библиотеки `go-libp2p`.
*   **Действия:** 
    *   Инициализировать Go-модуль.
    *   Настроить базовый узел `libp2p` с поддержкой DHT (Kademlia).
    *   Реализовать ручной ввод `PeerID` удаленного пира для установки прямого соединения.
*   **Definition of Done (DoD):** Приложение запускается на Компьютере А и Компьютере Б. При вводе ID соседа в консоли Компьютера Б мгновенно отображается строка «Привет», отправленная с Компьютера А.

### 🎨 Фронтенд (Фича: Ретро-интерфейс «Спутник»)
*   **Задача:** Верстка базового одностраничного интерфейса в духе ICQ 2003 / QIP 2005.
*   **Действия:**
    *   Создать каркас приложения на HTML/CSS/JS (с прицелом на Tauri для десктопной сборки).
    *   Сверстать левую панель со списком контактов, правую область чата и нижний статус-бар.
    *   Интегрировать легендарный звук «О-оу!» при клике на тестовые элементы.
*   **Definition of Done (DoD):** Десктопное приложение запускается локально в окне. Интерфейс адаптивен, кнопки кликаются, звуковое сопровождение работает локально.

---

## 📅 Спринт 2: «Первый Коннект» (E2E Интеграция)
**Цель спринта:** Объединить визуальный интерфейс и сетевое Go-ядро в единую рабочую десктопную программу.

### 💻 Бэкенд / Сетевое ядро (Фича: Local API Bridge)
*   **Задача:** Научить Go-клиент и JS-интерфейс разговаривать друг с другом.
*   **Действия:**
    *   Запустить внутри Go-приложения локальный WebSocket-сервер на `localhost`.
    *   Настроить трансляцию входящих P2P-сообщений из сети в WebSocket для фронтенда.
    *   Реализовать прием команд отправки сообщений от фронтенда через тот же сокет.
*   **Definition of Done (DoD):** Go-ядро успешно принимает JSON-сообщения от локального JS-кода и отправляет их в P2P-канал.

### 🎨 Фронтенд (Фича: Интеграция с ядром)
*   **Задача:** Подключить ретро-интерфейс к локальному API-мосту Go.
*   **Действия:**
    *   Написать JS-клиент для подключения к локальному WebSocket-серверу Go.
    *   Реализовать динамический рендеринг отправленных и полученных сообщений в окне чата.
*   **Definition of Done (DoD):** **Первый прототип готов к тестам!** Два члена команды запускают сборку на своих ноутбуках, обмениваются PeerID и переписываются напрямую в ретро-интерфейсе со звуками.

---

## 📅 Спринт 3: «Супер-нода и Статусы» (Стабильность и UX)
**Цель спринта:** Сделать поиск контактов автоматическим и вернуть легендарные статусы.

### 💻 Бэкенд / Сетевое ядро (Фича: Supernode Bootstrap & Statuses)
*   **Задача:** Настройка стабильного соединения через ваш сервер и обмен пользовательскими статусами.
*   **Действия:**
    *   Запустить и настроить постоянную «супер-ноду» (Bootstrap Node) на сервере `icq.works`.
    *   Разработать микро-протокол обмена статусами («В сети», «Ушел», «ДНД») напрямую между пирами.
*   **Definition of Done (DoD):** Приложения при старте автоматически находят друг друга через `icq.works` без ручного копирования сложных IP-адресов. Статусы друзей обновляются в реальном времени.

### 🎨 Фронтенд (Фича: Ретро-детали & UIN)
*   **Задача:** Добавление уникальной эстетики 2000-х и упрощение идентификаторов.
*   **Действия:**
    *   Реализовать генерацию коротких цифровых UIN (например, 6-7 знаков) на основе хэша PeerID, чтобы скрыть сложные технические адреса.
    *   Интегрировать звук пишущей машинки во время ввода текста в чат.
*   **Definition of Done (DoD):** Пользователь видит свой ретро-UIN в профиле и может добавить друга в список контактов просто по его цифровому номеру.

---

## 📅 Спринт 4: «Мобильный прорыв» (Гибридный P2P и Пуши)
**Цель спринта:** Запустить мессенджер на смартфонах без критического разряда батареи и с работающими уведомлениями.

### 💻 Бэкенд / Сетевое ядро (Фича: Blind Push Gateway)
*   **Задача:** Создать приватный шлюз для «побудки» мобильных клиентов.
*   **Действия:**
    *   Развернуть на VPS защищенный легковесный шлюз для отправки пушей (через Firebase Cloud Messaging или APNS).
    *   Реализовать отправку «слепого» зашифрованного сигнала о новом сообщении, когда мобильный получатель ушел в офлайн.
*   **Definition of Done (DoD):** На заблокированный смартфон приходит системное уведомление «Новое сообщение!», не раскрывая шлюзу текст сообщения и отправителя.

### 🎨 Фронтенд (Фича: Mobile Build & P2P-lite)
*   **Задача:** Адаптация и сборка клиента под iOS / Android в режиме пониженного энергопотребления.
*   **Действия:**
    *   Упаковать фронтенд для мобильных платформ (используя встроенные мобильные билды Tauri или Capacitor).
    *   Переключить мобильное приложение в режим "P2P-lite" (оно не участвует в раздаче чужих пакетов DHT, а общается только со своей десктопной супер-нодой или сервером, когда активно).
*   **Definition of Done (DoD):** **Финальный MVP готов!** Мессенджер работает на смартфонах, присылает пуши из спящего режима и не разряжает батарею за пару часов.
